# pull

A source enters by a line in `ref/README.md` and its platform's puller, per
[Pullers](../../../docs/ARCHITECTURE.md#pullers). Never a capture written any other way, and never a link
a puller printed followed without registering it.

- `yt-pull.rs transcribe` spends per video, and with no arguments takes the whole unticked backlog. Name
  the videos: `transcribe <url>...`
- commit the pull before [call-digest](call-digest.md) runs on it
- a channel or speaker not yet known: [people.md](people.md)
